# 拾光CampusGo 使用说明（评委 / 普通用户）

> 面向实际体验者。项目默认进入**真实数据模式**，所有用户数据保存在服务端 MySQL，刷新与重登都在。
> 记录日期 2026-11-24。

## 一、启动与访问

```bash
npm install
npm run dev          # 后端 3000 + 前端 5173 同时起
```

浏览器打开 `http://localhost:5173`（手机 / 平板同网段可用本机局域网 IP，见 README「让其他设备访问」）。需本机 MySQL 8.4 在 3307 运行且 `apps/server/.env` 配好 `DATABASE_URL`（见 [部署指南](deployment-guide.md)）。

## 二、真实模式 vs 演示模式

- 页面右上角数据源开关默认 **「真实接口」**：地点 / 挑战 / 徽章 / 天气 / 用户数据全部来自后端与数据库。
- 拨到 **「示例数据」** 可看一份明确标注的演示内容（仅前端展示，**不写入数据库**），用于无后端时预览界面。演示模式全程挂「示例数据 / 演示交互」标签，不会冒充真实数据。
- **后端关闭时真实模式如实报错**（失败条 + 重试），不自动回落到示例数据冒充成功。

## 三、注册 / 登录 / 退出

1. 未登录时，首页进度条、个人中心、记忆、搭子管理等功能给**诚实的登录入口**（不拿固定数字冒充你的账号）。地点 / 挑战 / 徽章**定义**与公开活动列表无需登录即可浏览。
2. 点「注册」填昵称 / 学校 / 口令（口令 scrypt 摘要存储，不明文），注册成功自动登录；用户码形如 `CG-2026-NNNN`。
3. 登录后**启动自动恢复会话**（`GET /api/auth/me`），刷新页面昵称 / 经验 / 积分 / 完成记录 / 收藏 / 规划全部从服务端取回。
4. 个人中心「退出登录」真清会话并跳登录页，不是假弹窗。

## 四、六页面功能

### 首页 Home
- **我的进度**：等级 / 称号 / 经验 / 积分 / 挑战完成数，来自服务端账号（未登录给登录入口）。
- **天气卡**：和风天气实时天气（江苏大学·镇江），后端代理，10 分钟缓存。
- **今日三件小事**：勾选任务真实写入服务端（经验 / 积分即时入账），未登录勾选给登录提示、不发请求不伪造完成。
- **推荐活动**：真实活动列表（报名 / 详情跳兴趣搭子页）。
- **AI 个性化推荐位**：明确标 **「暂未开放」**，给「去用规则规划」「先看看校园地点」两个可用入口，**不拿固定文案冒充模型输出**。

### 生活规划 Plan（原「AI生活规划」，已如实更名）
- 选空闲时间 / 兴趣 / 预算 / 心情 / 同伴，点生成**瞬间出结果**（前端规则模板匹配，**非 AI**，无假延迟）。结果卡明确标注「规则模板规划 · 地点为核实存在的江苏大学与镇江地点，价格与时长是规则估算」。
- **地点面板**：真实 12 个核实地点，可筛选 / 看详情 / 收藏（心形按钮走真实 `/api/favorites`）。
- **保存 / 管理我的规划**：登录后可保存（`POST /api/plans`）、载入、重命名、删除，刷新仍在；未登录给登录入口。

### 趣味挑战 Challenge
- 7 条系统任务模板（3 日常 + 4 探索）+ 9 枚徽章定义，公开可读。
- 勾选完成 / 取消走真实 `/api/tasks`，经验积分服务端入账，**重复完成被拒（409）**，撤销按快照回滚。
- 徽章由服务端按你的完成记录判定，达标自动点亮；可点「重新判定徽章」。完成记录 / 徽章未取回时显示「未取到 / 未判定」，不拿 0 冒充。

### 时光记忆 Memories
- 登录后可**新增 / 编辑 / 删除**记录（真实 CRUD，绑定当前账号，跨用户隔离），刷新仍在。
- 地点候选来自真实地点库；删除有确认弹窗「删除后服务端记录会被移除，无法恢复」。
- **照片上传暂未开放**（DEFERRED）：真实模式给明确提示，不做假上传；演示模式保留示意网格并标注。

### 兴趣搭子 Partners
- 公开发现活动列表（无需登录），可筛选兴趣 / 分类。
- 登录后可**发布活动**（主办人 = 你）、**报名 / 取消报名**（名额服务端实时计数，满员 / 已取消 / 已结束拒绝报名）。
- **主办人专属**：编辑 / 取消自己的活动（越权 403/404）；取消后活动标「已取消」，报名 / 编辑按钮消失。
- 空库时给诚实空态「数据库里现在还没有任何活动」+ 发起入口，**不预造假活动**。

### 个人中心 Profile
- 真实资料（昵称 / 签名 / 学校 / 专业 / 年级 / 用户码 / 注册时间），编辑走 `PATCH /api/auth/me`，**不泄露 password_hash 与内部 ID**。
- 兴趣标签 / 偏好开关：服务端权威，读写闭环（`PUT /api/preferences/batch`），刷新仍在。
- 收藏地点：真实 `/api/favorites` 列表与取消。
- 五格统计（经验 / 积分 / 完成 / 徽章 / 记忆）按取回状态显示，未取回写「未取到」。
- 修改密码、退出登录均为真实操作。

## 五、诚实空态与错误体验

- 库里 0 行 ≠ 取数失败：空态会区分「数据库里当前是 0 条」与「没有取到，请重试」。
- 失败按类别显示「哪一类问题 + 下一步做什么」，只在重试有意义时挂重试按钮。
- 未登录 / 被禁用 / 后端不可达三种情况文案各不相同，**问不到后端时不替后端宣布任何结论**。

| 独立地图探索页 / 导航 | 已取消（见 [Explore 取消报告](explore-removal-report.md)） |
| 活动聊天消息通道 | 未立项（报名真实写入，聊天说明如实标注） |

## 七、数据归属一句话

**真实模式下你的每一个操作都写在服务端数据库里，绑定你的账号，刷新和重登都在，别的用户看不到也改不了。** 演示模式只是明确标注的界面预览，不碰数据库。
