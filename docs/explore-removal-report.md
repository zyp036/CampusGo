# 校园探索（Explore）页面取消报告

> 状态：**已取消（产品决策）** · 记录日期 2026-11-24 · 对应原阶段 6「校园探索和地图」
> 依据：用户最终收尾指令六「保留天气与地点数据，不做地图导航，不删地点数据库」与产品调整决策（2026-11-23）。

## 一、取消原因

1. **产品范围收敛**：独立「校园探索」页与高德地图导航不再是本项目功能。项目定位为「AI 校园生活探索与娱乐规划平台」，地点发现能力并入「生活规划」页与「个人中心」收藏区即可满足需求，单独维护一个地图探索页收益低、依赖重。
2. **第三方地图依赖与密钥风险**：高德地图 JS API 需要前端密钥与安全密钥配套，且阶段 6 实测 AMap 2.0 在 `viewMode:'2D'` 下标记渲染失败（`Pixel(NaN,NaN)`），降级 1.4.x 后仍不稳定（见项目记忆「阶段6 高德地图 BLOCKED」）。继续维护地图组件会引入不可控的第三方故障面与密钥管理负担。
3. **AI 暂缓的连带决策**：阶段 5 AI 个性化规划整体 DEFERRED，地图导航作为其配套展示能力一并搁置，避免留下「半接入」的假功能。

取消是**产品决策**，不是技术失败遗留：地点数据本身真实可用，取消的只是「独立地图探索页」这一展示形态。

## 四、数据库影响

**零改动**。取消 Explore 页未删除任何地点记录、未改 `cg_campus_place` 结构、未清空数据库。坐标列（经纬度）保留为地点数据属性，注释中过时的「地图搜索和路线规划」用途描述已在收尾 A6 改为「独立地图页已取消，作为地点数据保留」，**列与数据一律不动**，`prisma validate` 通过。
